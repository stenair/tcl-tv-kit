# Debloat list: TCL 75C755 QD-Mini LED, Google TV 14 (device G08, MediaTek tcl9618,
# firmware tcl9618-user 14 UTT2.250416.001 AU02), as applied on 2026-11-05. Australian apps.
# Based on CleanYourTV's examples/tcl-c755-google-tv/debloat.txt (verified on two C755s with this firmware),
# adjusted for this household: see the kit's docs/03-debloat.md for every decision.
#
# Every line is DISABLED for user 0, never uninstalled. "#" in front of a line keeps that package ON.
# Copy this file to CleanYourTV\work\<your tv>\debloat.txt and KEEP IT THERE: the undo record is keyed to its path.
#
# Apply (PowerShell, from the CleanYourTV folder):
#   powershell -ExecutionPolicy Bypass -File tools\disable.ps1 -TvHost $env:TV_HOST work\<your tv>\debloat.txt
# Undo everything (back to the original state, Google TV's home included):
#   powershell -ExecutionPolicy Bypass -File tools\restore.ps1 -TvHost $env:TV_HOST work\<your tv>\debloat.txt -Stock com.google.android.apps.tv.launcherx
# Undo one package:  tools\venv\Scripts\python.exe -I tools\tv.py "pm enable <package>"
# After a firmware update:  tools\venv\Scripts\python.exe -I tools\check.py work\<your tv>\debloat.txt
#
# KEPT ON by choice (ask your household; these are ours):
#   com.google.android.apps.mediashell      Chromecast (we cast from phones)
#   com.google.android.katniss              Google Assistant / Gemini on the mic button
#   com.google.android.tv.remote.service    also carries the Bluetooth remote's mic: never disable
#   com.tcl.gamebar                         game mode / VRR overlay (PS5)
#   com.tcl.channelplus                     TCL Channel free live channels (it is also their TV input)
#   com.tcl.interactive                     TCL's HbbTV engine: disabling it makes the TV app retry it 10x a second
#                                           forever (see below); kept on
#   Netflix, Prime Video, YouTube, and every app you installed
# KEPT ON because the TV needs them: com.tcl.tv (the only HDMI player!), com.tcl.tvinput (HDMI inputs),
#   com.tcl.dashboard and com.tcl.suspension (the Input button's source panel; also reused as the Cameras and PS5
#   tiles), com.tcl.autopair, com.tcl.systemserver, com.tcl.providers.config, com.tcl.initsetup,
#   com.tcl.useragreement, com.tcl.globalkeyoverlay, com.tcl.systemui.plugin, com.tcl.factory.view,
#   com.tcl.inputmethod.international (keyboard), com.tcl.eva, com.tcl.hearaid, com.tcl.t_solo, tv.mopa.ginga,
#   com.tcl.android.webview, all com.mediatek.* except AirPlay, com.dolby.*, Play Store and Play Services.
#
# Firmware updates: TV Settings' System update screen is Google Play Services
# (com.google.android.gms/.update.SystemUpdatePanoActivity), which stays on. com.tcl.ttvs also carries TCL's own
# update service; to use that path: tv.py "pm enable com.tcl.ttvs", check for updates, then apply this list again.
#
# Apply in batches (remove the batches you haven't reached yet, or apply the whole file and check after each
# batch's packages show "disabled-user"), with a screenshot and a quick look between batches.
